# Get Involved assets

Save the six original card photos here with these filename stems. PNG, JPG, JPEG, WebP and SVG work; uppercase raster extensions are supported. Assets are detected automatically in development. Rebuild and redeploy after adding files to the hosted site.

- `careers`
- `volunteer`
- `collaborate`
- `fellowship`
- `donate`
- `contact-us`

Optional original icons replace the default inline icons when supplied:

- `icon-careers`
- `icon-volunteer`
- `icon-collaborate`
- `icon-fellowship`
- `icon-donate`
- `icon-contact-us`
- `icon-phone`
- `icon-email`
- `icon-location`

Card actions currently open an email enquiry, except Contact Us, which scrolls to the contact panel. Replace their hrefs in `src/getInvolvedData.js` when dedicated application forms, job listings or an approved donation destination are supplied.
